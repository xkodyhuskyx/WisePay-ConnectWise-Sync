Guide: How To Create ConnectWise API Credentials Expand for step-by-step instructions

Create a dedicated, limited-access API member before completing the settings below.

  1. Create A Security Role Optional · Recommended

    1. Go to System > Security Roles.
    2. Click the + (New Item) icon.
    3. Enter a descriptive Role ID, such as WiseSync_Helper_API, and save it.
    4. Expand the permission modules and grant only the access this integration needs. This helper reads company, contact, and company-site information.
    5. Click Save.

  2. Create The API Member

    1. Go to System > Members, then open the API Members tab.
    2. Click the + (New Item) icon.
    3. Enter a Member ID and Member Name, then select your new security role for Role ID.
    4. Set Level to Corporate (Level 1) and save.

  3. Generate The API Keys

    1. Open the new API Member profile.
    2. Open the API Keys tab and click the + (New Item) icon.
    3. Enter a description, such as Wise-Sync Guest Checkout Helper, and save.
    4. Copy the displayed Public Key and Private Key into the fields below.
    Save the private key immediately. ConnectWise displays it only once. It cannot be viewed again after you close or refresh the page.

  4. Create A Private Client ID

    1. Open the official ConnectWise Developer Network and log in, or register for a developer account using your corporate email address.
    2. Open the Client ID or ClientID tab and choose Create New Integration.
    3. Enter a recognizable integration name and describe this helper as an internal Wise-Sync checkout tool.
    4. For Integration Type, always select Private. Select Manage (PSA) for the product and enter your administrator or developer email as the technical contact.
    5. Submit the request. Copy the generated Client ID GUID from your active integrations list and paste it into the Client ID field below. It may take up to an hour to appear if ConnectWise reviews the request manually.

Security Notice

Credentials are encrypted locally, but this does not protect against malware or someone who already controls your operating system account. Use this only on trusted computers.
